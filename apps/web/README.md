# EduConnect AI - Web App

## Phase 1 Frontend

This is the React + Vite frontend for EduConnect AI, created for the Ganpat University Hackathon 2026.

## Technologies Used
- React 18
- Vite
- TypeScript
- Tailwind CSS
- React Router
- Lucide React

## Execution Instructions

To run the web app in development mode:
```bash
cd apps/web
npm install
npm run dev
```
Open `http://localhost:5173/` in your browser.

## Demo Features Implemented
- Landing Page
- Demo Login for Student, Faculty, and Admin
- Protected Routing Based on Role
- Role-Specific Dashboards
- Application Layout with Sidebar

To build for production:
```bash
npm run build
```
